## 📖 نبذة عن المشروع
**بوستيرا (POSTERA)** هو متجر إلكتروني سريع وخفيف مصمم بأحدث معايير الويب بدون أي مكتبات أو أطر عمل ثقيلة (Vanilla Stack). المتجر متخصص في تقديم بوسترات ديكورية فاخرة مطبوعة على ألواح ألومنيوم بسُمك 1.1 مم، مقاومة للخدش والرطوبة مع تأثير لمعان معدني فريد.

---

## ✨ المميزات الرئيسية
* **تصميم غامق فاخر (Dark Metallic Aesthetic):** ألوان وتدرجات ذهبية ومعدنية مع تأثير تفاعلي لانعكاس الضوء على اللوح المعدني (*Brushed Metal Sweep Animation*).
* **معرض أعمال فنية جاهزة:** تشكيلة من اللوحات الفنية المرسومة برمجياً بدقة فائقة عبر SVG (فضاء، طبيعة، مدن، مصر، تجريدي).
* **قسم الطباعة الخاصة (صورتك على معدن):**
  * إمكانية رفع الصور بالسحب والإفلات أو من الموبايل.
  * اختيار المقاس (20×30، 30×45، 40×60، 50×75 سم).
  * اختيار الاتجاه (طولي / عرضي) وطريقة التمدد (تملا اللوحة / الصورة كاملة).
  * اختيار نوع التشطيب (لامع / مطفي).
  * **فاحص جودة ذكي (DPI Quality Advisor):** يقيم دقة ووضوح الصورة المرفوعة قبل إتمام الطلب لتفادي الصور غير الواضحة.
* **سلة تسوق ونافذة دفع منبثقة (Cart Drawer):**
  * حساب فوري للأسعار، الكميات، وإجمالي الشحن.
  * شحن مجاني تلقائي للطلبات التي تتخطى الحد المحدد.
  * دعم كامل لجميع محافظات مصر الـ 27 والتحقق من صحة أرقام الموبايل المصرية (`01xxxxxxxxx`).
  * دعم الدفع عبر **إنستا باي (InstaPay)** ومحافظ كاش الإلكترونية (فودافون كاش وغيرها) مع زر نسخ سريع للحساب.
  * إرفاق لقطة شاشة لإيصال التحويل وتوليد رقم طلب فريد ببادئة `PST-`.
* **لوحة إدارة مخصصة للمدير (`/admin`):**
  * تسجيل دخول آمن عبر Supabase Auth (بدون تسجيل عام للزوار).
  * متابعة الطلبات الأحدث، إحصائيات حية، وبحث وفلترة بالحالة.
  * فحص إيصالات وسكرينات التحويل ومقارنة المبلغ المحول بالمطلوب مع تنبيه فوري.
  * تحميل صور وتصميمات العملاء الأصلية بجودتها الكاملة للطباعة بنقرة واحدة.
  * تحديث حالات الطلب ومراسلة العميل بالواتساب مباشرة.

## 📂 هيكل المشروع
```text

├── index.html           # واجهة المتجر الرئيسية

└── README.md            # توثيق المشروع
```

## 🚀 طريقة التشغيل والنشر

### 1. التشغيل محلياً:
فقط افتح ملف `index.html` في أي متصفح، أو استخدم إضافة مثل `Live Server` في VS Code.

### 2. النشر على GitHub Pages:
1. ارفع المشروع إلى مستودع GitHub جديد.
2. من إعدادات المستودع (**Settings**) ⬅️ توجه إلى **Pages**.
3. في خيار **Build and deployment**، اختر الفرع `main` والمجلد `/ (root)`.
4. اضغط **Save** وسيكون متجرك متاحاً أونلاين على الإنترنت مجاناً خلال ثوانٍ!
